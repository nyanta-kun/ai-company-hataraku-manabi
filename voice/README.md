# voice/ 読み上げの音声ファイル

アプリの読み上げに使う音声ファイル（声のパック）を置く場所です。設計は `docs/design-voice.md`、企画は `docs/plan-voice.md`。

- `voices.js` … 同梱している声の一覧（保護者画面の並びと、おまかせの先頭）。build.js が書く
- `<id>/index.js` … その声のパック（読み上げ文 → ファイル名・長さ）
- `<id>/*.aac` … 音声（AAC）
- `<id>/README.md` … クレジット・規約の URL と確認日・作り方の記録

## 音声の扱い

ここの音声は、このアプリの読み上げのためだけに作ったもので、リポジトリのコードのライセンスの対象外です。**自由に使える素材ではありません。** 使いたい場合は、VOICEVOX と各キャラクターの利用規約に従ってください（キャラクターの規約の URL は各声の README に書きます）。

## 手元で確かめるとき

`file://`（`index.html` を直接開く）では音声ファイルを読めないので、今までと同じ端末の声になります。音声ファイルの声は `python3 -m http.server 8000` で開いて確かめます。
