## 決めたこと
- 国語の誤答: 単語表の8文字のみ。K1 は A グループ内、K2/K3 は8文字全体。K1・K2 は「行」が違う文字だけ出す。K3 は形が似た文字を混ぜてよいが、表の文字で組になるのは は–ほ だけ（他の組は相手の文字が単語表に無いので混ざらない）。
- 数の選択肢は昇順に並べる。たしざん M5 は和6以上を約75%（性質5は半分以上）。
- 出動の現場は3種を持ち回り（直前と同じ現場は避ける）。UI の経過は「4つのランプ」と現場の変化（火が小さく／はしごが伸びる／がれきが減り救急車が来る）。
- 日本語の読み上げ文は漢字・カタカナまじりで、文節の間にスペースを入れない（ひらがなだけ・分かち書きだと、端末の読み上げが語の切れ目やアクセントを決められず平坦になる）。語の読みは `data.YOMI`（もじの語）・`data.CAR_YOMI`（車）、無ければカタカナ表記。文字の音（「はしごの は」の「は」）と時刻（「よじはん」）・数（「よん」「なな」）はひらがなのまま。足し算は数字で渡す（「に たす」の「に」が助詞に読まれないように）。日本語は rate 0.9・pitch 1.0。
- 声なしモード: `speechSynthesis` が無い、日本語音声が1.5秒以内に見つからない、読み上げ開始が2回連続で来ない、のいずれかで切り替え。声なし（または読み上げオフ）の国語は1回目の誤答で正解ボタンを光らせる。算数は数えるものが1つずつ跳ねて「ぽん」の音程が上がる。
- 描画は論理幅 800 固定・高さは canvas の縦横比に合わせる（スマホ縦横・PC で同じコード）。
- 長押し2秒: タイトルの歯車（保護者画面）、問題画面の×（タイトルへ）。
- 「もういちどきく」ボタンは、スマホ縦の幅360px でも答えボタン 72px を確保するため、企画書の左下ではなく上部右に置いた。
- 乗り物の向き（規約）: 絵の「前」の向きは `vehicles.js` の `FRONT`（既定は左向き=-1。ねこぐるま1・フォークリフト2・しょべるかー4 だけ右向き）。`drawVehicle(ctx, stage, x, y, size, facing)` の facing は前を向ける向きで、既定 1（右）。絵の前と違うときだけ内部で左右反転する。走る・動くときは進む側に前が来るようにする（しゃこ・タイトルは右へ走るので既定の右）。画面に止めた車は付属物（はしご・放水口）が目標に合う向きにする（kaji・takai の 8・10 は -1、michi に左へ来る救急車も -1）。新しい乗り物（plan-katakana-english.md 2.8）は前を左に描けば FRONT に載せず済む。反転は `drawVehicle` の ctx.save/restore の中だけで、車体に文字を描くなら反転しない側（呼び出し側）で重ねる（今の絵に文字は無い）。
- 乗り物の音: `audio.js` の `car1`〜`car11` = `CARS.stage`（`carSound(stage)`）。しゃこのタップは車ごとの音、出動時は現場の車（kaji=8、takai=10、michi=4）、michi の最後に救急車(7)。しょうぼうしゃは長い「ウーーー」+ 鐘、きゅうきゅうしゃは「ピーポー」。乗り物の音は同時 2 つまで。
- 全車★3 の後の「ごほうびステッカー」は、カード画面で文言だけ出す（U5: 未実装）。

## もじの単語表の拡充（docs/plan-katakana-english.md 2.3・2.8・2.9。B1・B2）
- 新しい絵 23 個は `vehicles.js` の `pics`（id は 'v' で始めない）。横から見る乗り物は前を左に描き、`drawPic` が facing で反転する。向きのない小物は反転しない。`#debug:pics`（または「えいちらん」ボタン）で全語の絵を一覧できる。
- 出題は `generateSession('letter', level, rng, recentPics)`。同一出動の規則と、直近の絵（`seen.letter`、古い順・末尾が最新・最大12）の除外は 2.9 のとおり。直近の除外は、規則を満たせないとき直前の出動の4枚まで緩める（K1 は語が少ないため）。
- 形が似た文字は、K1・K2 では誤答に混ぜず、K3 は最大1つ。plan にない け–は、く–へ を `CONFUSABLE` に足した。


## カタカナ（もじ K4〜K6。docs/plan-katakana-english.md 2.1〜2.7・B3）

- `data.js` の `KATA_WORDS`（17語。`WORDS` の `kata` 付きから作る。id は `_k`、label はカタカナ、speech・example はひらがな）、`ALL_WORDS`（48語）、`EXTRA_KATA`（ケ・プ・ボ・ベ・ド・ツ と例語）、`CONFUSABLE_KATA`。カタカナの ROW・FAMILY は対応するひらがなと同じ（追加文字は個別）。
- K4=カタカナ2択（似た文字・追加文字なし、行ファミリーが違う文字だけ）、K5=カタカナ4択（似た文字を最大1つ。追加文字も相手にできる）、K6=ひらがな語・カタカナ語の混在4択。選択肢の文字種は出題語の表記にそろえるので、だ と ダ は同時に出ない。K6 の出動は両方を1問以上含み、答えの音（`toHira`）が同じものも2度出さない。
- 消防と乗り物を1問ずつ入れる規則は、候補ではなく出題元全体で判定する（K5 のように語が少ない表で、直近の除外により消防が候補から消えても満たせるようにするため）。
- 偏りの検証（性質13）は、K6 だけ絵ごとに数える（同じ絵のひらがな語・カタカナ語が出番を分け合うため）。
- UI の文言はひらがなのまま。カタカナは問題の文字（選択肢）だけ。

## とけい（docs/plan-clock.md の実装。未決事項は推奨案で決めた）
- C1: T1 の誤答は 12 を一周する数え方で 3 以上離す。C4: T3 は 12 時台（12:30）も含める。C6: 昇降級は4/4・0〜1/4 をそのまま使う。C9: アイコンは丸い時計、並びは かず・もじ・とけい。
- C11: 選択肢の小さい時計も数字は 12 個（`opts.numbers: 4` で 4 個に切り替え可。幅 360 縦の実測で 12 個でも読めた）。
- 時刻の読みは `data.TIME_KANA`（よじ・しちじ・くじ）。○じはん は末尾に「はん」。数の読み（NUM_KANA）は使わない。
- 取り違え誤答 `swap:h`（短針 12・長針 h）は m=0 かつ h≠12 の問題にだけ、`h:mm` とは別のキーで出す。選択肢は全ペアで「長針60度以上 または 短針30度以上」ちがう絵だけを並べる（swap と隣の 12:00 は両立しないので、h=1・11 で 12:00 が先に選ばれたときは swap を省き、他の時刻で補う）。
- 誤答の読み上げは `h:mm` なら「{よじ}。おしい！もう一回。」、`swap` は読み上げ不能なので「おしい！もう一回。」だけ。ヒントは T1 が「短い針を見てね。」＋短針をふくらませる、T2/T3 は正解の時計の短針をふくらませる。声なし（または読み上げオフ）の T3 は 1 回の誤答で正解が光る。
- 出動えらびは3ボタン（幅 360 縦で 94px×3 が 1 行に収まる。`.pick-box .big` の横 padding を 6px に詰めた）。時計の答えボタンは 2×2、高さ `clamp(112px, 20vh, 150px)`。
- 答えボタンを出したあとに `stage.resize()` で現場の Canvas を測り直す（時計ボタンが高く、測り直さないと縦に伸びて時計が楕円になる）。
- 保存データは `levels.clock`・`locked.clock`・`stats.clock` を足しただけ（バージョン 1 のまま、`normalize` が旧データを補完）。

## えいご（4つめのミニゲーム）の実装メモ
- 構成: 語彙 `data.ENGLISH_WORDS`（14語）・`NUM_EN`、問題生成 `problems.generateEnglish / generateSession('english')`（`tests/english.test.js`）、読み上げ `speech.speakSeq`（`tests/speech.test.js`）。E1=乗り物の英語→絵3択（4問とも乗り物）、E2=乗り物2問（絵3択）＋英語の数1〜5を2問（3択）、E3=乗り物2問（絵4択）＋数1〜10を2問（4択）。数ばかりにならないよう E2/E3 にも乗り物を混ぜる。1出動は答えが重複しない4問。出題は英語のあと日本語で「どれかな？」だけ言い、英語の意味（しょうぼうしゃ・さん）は日本語で言わない。`seen.english` は持たない（出動内の重複回避のみ）。
- 英語の声の選び方: en-US かつ端末内 → en-* かつ端末内 → en-US の端末外 → en-*。**端末外の声は日本語と同じく最後の手段として許可する（暫定判断。企画 U6 は未決）**。ノベルティ・機械的な声・Eloquence 系（Zarvox・Bells・Fred・Junior・Ralph・Kathy・Eddy・Flo・Grandma・Grandpa・Reed・Rocko・Sandy・Shelley など）は名前で除外する。実機での確認は未了（U7）。
- 判定は言語ごとに分離（`failed` / `noStart` / `reason`）。英語が失敗しても日本語は声なしにならない。連続読み上げ `speakSeq` は、発話が3秒始まらなければ synth.cancel() で捨てて次へ進み（seq は進めない）、日本語を詰まった英語の後ろで待たせない。前の発話の後ろで待っていた発話は開始失敗に数えない。
- 英語の声が使えないとき（声なし・失敗・保護者が読み上げオフ）は、出動えらびの「えいご」をグレー＋スピーカー×にして出動させない（タップで「おしい」音と、日本語の声があれば「英語の声が、ないよ。」）。判定は画面を開くたびと声の状態が変わるたびに見直す。出動の途中で失敗したら続行し、英語を字幕で出して、1回目の誤答で正解を光らせる。
- E2/E3 は正解後の数え上げ（one, two, ...）を最後まで読ませてから次の問題へ進む（上限15秒）。数のものは正解時に一度に表示する（1つずつは出さない）。
- E1 の選択肢は `group` が違う語だけ。「〜 truck」系（truck・fire truck・dump truck・garbage truck）は同じ group にして並べない。
- 出動えらびは4ボタン（縦 2×2・横 4列）。`#debug:play-english-E1-kaji-0`、確認パネルに E1〜E3 と「えいご声なし」（切替）。

- `index.html#debug` で確認パネル（レベル切替・全車★3・声なしモード・エラー表示 `#errlog`）。`#debug:play-math-M3-kaji-2`（画面-ゲーム-レベル-現場-進み）、`#debug:play-letter-K3-takai`、`#debug:play-clock-T3-kaji-0`、`#debug:reward-kaji`、`#debug:garage`、`#debug:parent`、`#debug:pick` で画面へ直接移動。
