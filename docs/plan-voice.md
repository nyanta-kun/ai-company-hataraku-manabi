# 追加企画「読み上げを自然な声にする（VOICEVOX の声と、声の切り替え）」

作成: 設計部 / 日付: 2026-10-27 / 状態: 企画（実装前。ユーザーに確かめる点は 9 章）。設計は `docs/design-voice.md`

- 依頼（原文）: 「声もすすめて。声の切り替えも用意して」
- 前提にした調査部の推奨: VOICEVOX の声で読み上げ文を前もって音声ファイルに書き出して同梱し、Web Audio で鳴らす。音声ファイルが無い文は今の端末の声（Web Speech API、`src/speech.js`）で読む。英語は端末の声のまま。クレジット「VOICEVOX:キャラ名」を保護者画面の「このアプリについて」に常に出す。

## 1. 目的と、変えないもの

- **目的**: 端末の声（iPad・iPhone の日本語の声）は抑揚が平らで、時刻・数・「は」の読みが揺れる（`docs/design.md:27` の苦労はその回避策）。前もって作った自然な声にして、4〜8 歳が聞き取りやすく、聞いていて楽しい読み上げにする。保護者が声を選べるようにする。
- **変えないもの**
  - ビルドなし・classic script・外部ライブラリなし。`file://` で開いても遊べる（このときは今の端末の声。6 章）。
  - 読み上げを呼ぶ側（`src/ui.js` の `say`・`seq`、`ui.js:249-250`）の形。読み上げ文の中身も変えない（同じ文を、ファイルがあればその声で、無ければ端末の声で読む）。
  - 英語は端末の声（`speech.js` の英語の声の選び方 `speech.js:15-27` をそのまま）。
  - 声なしモードの考え方（声が出せないときは正解を光らせる、`docs/design.md:28`）。
  - 通信は GitHub Pages から自分のファイルを読むだけ。外部のサービスへ送らない。

## 3. 何を音声ファイルにするか（読み上げ文の洗い出し）

詳細は設計 3 章。読み上げに渡る日本語の文は、全レベルの出題を機械的に出して数えると **約 3,550 通り**（ゲーム 2,780・かく 640・決まり文句と乗り物など 130）。大半は「時刻×（正解・誤答）」（とけい T7 だけで 1,440）と、2 けたの式（かず M12 で 620）。

- **文ごとに全部作る案**は 1 人あたり約 3,550 ファイル・約 35MB で、声を変えるたびに重く、文言を直すたびに履歴が太る。
- **推奨: 決まった文は 1 つの音声、変わる部分（数・時刻・式の数）は部品にしてつなぐ**。「おしい！もう一回。」「どのとけいかな？」は丸ごと 1 つ、「くじ」「よんじゅうきゅうふん」「にじゅう」「たす」は部品。**1 人あたり約 1,200 ファイル・約 6〜8MB**（見積もり。±30%）。
  - 数がともに 10 以下の式（たしざん・ひきざん、約 155 通り。S0 の式はすべてここに入る）と、「よじはん」のような ちょうど・はん の時刻は、つなぎ目の無い丸ごとの音声にする（いちばん聞く文を自然にする）。
- **子どもの名前**（ひらがな 6 文字まで、`ui.js:179`・`ui.js:546`）は前もって作れない。**推奨: 名前を呼ぶ文だけは端末の声で読む**（名前を呼ばれる楽しさを残す）。端末の声が無い端末では、名前を抜いた文（「しゅつどうの じゅんび！」）を VOICEVOX の声で読む。
- 英語は作らない（端末の声）。えいごの「どれかな？」「そう！」など日本語の部分は VOICEVOX の声。

## 4. 声の切り替え

- 保護者画面の「おと」に「こえ」を足す: `たんまつの こえ` / `めたん（VOICEVOX）` / `ずんだもん（VOICEVOX）`。選ぶとその声で「こんにちは。はたらくまなびです。」を読む。
- **端末ごと**に覚える（`storage.js:130` の `device.sound` に足す。効果音・読み上げのオン/オフと同じ所。`docs/design-elementary.md:80` の「音が出る・出ないは端末の都合」と同じ考え）。プロフィールごとにする案は、兄弟で声を分けたい要望が出てからにする（設計 7.3）。
- **既定**: VOICEVOX の声 1 人目（四国めたん）。Web（https）で開いていて、音声が読めるときだけ。読めないとき（`file://`、通信できない、復号できない）は黙って端末の声で読む。
- 声ごとにフォルダを分け（`voice/metan/`・`voice/zundamon/`）、**選んだ声のファイルだけを読む**。声を増やしてもアプリが重くならない（リポジトリと公開サイトが大きくなるだけ）。

## 5. 鳴らし方（要点。設計 5〜6 章）

- 効果音（`src/audio.js`）と同じ 1 つの AudioContext で鳴らす。最初のタップで解放する今の流れ（`ui.js:252-256`）に乗る。
- 出動を始めるとき、その 4 問で読みうる文（問題・正解・誤答・ヒント・数え聞かせ）の音声を先に読んで復号しておく（1 回の出動で 30〜60 ファイル・数百 KB）。間に合わない文（0.8 秒待っても）だけ、その文を端末の声で読む。
- 部品のつなぎ目は短い間（文の中 0.04 秒・文と文 0.2 秒）。音声の頭とおしりの無音は、復号したときに測って切る。
- 1 つの文を 2 つの声で混ぜて読まない（足りない部品があれば、その文全体を端末の声で）。
- 失敗（読めない・復号できない・鳴らない）が続いたら、その日はずっと端末の声に戻る。

## 6. `file://` とオフライン

- `file://` で開いたときは、今と同じ端末の声だけで遊べる（ブラウザが `file://` の音声ファイルを fetch で読ませないため。設計 6.4）。VOICEVOX の声は Web（GitHub Pages）で開いたときの機能。手元で確かめるときは `python3 -m http.server` で開く。
- オフライン（機内モードなど）も端末の声に戻る。今のアプリにオフライン用のしくみ（Service Worker）は無く、今回も足さない。

## 7. 大きさと公開

- 1 人あたり約 6〜8MB、2 人で約 15MB（見積もり）。GitHub Pages の公開サイトの上限 1GB、リポジトリの推奨 1GB 以下・1 ファイル 100MB 未満に十分収まる（設計 8 章）。
- 文言を直したら、変わった文の音声だけ作り直す（全部は作り直さない）。履歴が太りすぎないようにする。
- CI の公開対象（`.github/workflows/ci.yml:37` の `cp -R index.html css src`）に `voice` を足す。
- **費用**: 無料（VOICEVOX・Docker のエンジン・macOS の afconvert）。有料サービス・API キーは使わない。Docker Desktop を使う場合は、個人・小規模事業は無料（大企業は有料）。推奨はアプリ版 VOICEVOX（無料）なので承認は要らない。
- **承認が要る点**: main へのマージでテスト版（GitHub Pages）が更新される（`ci.yml:17-43`）。**音声を初めて含む PR のマージは Web 公開に当たるので、マージ前にユーザーの承認をもらう**。

## 8. 進め方（PR の切り方。設計 12 章）

1. **PR1 読み上げ文を 1 か所に**: `ui.js` に散らばる読み上げ文を作る関数を `src/lines.js`（純粋関数）へ移す（読む文は 1 文字も変えない）。全レベルの読み上げ文を一覧にする `scripts/voice/list.js` とテスト。見た目・音は変わらない。
2. **PR2 鳴らすしくみ**: `src/voice.js`（文→音声の部品への分解・読み込み・再生）、`speech.js` の切り替え、選んだ声の保存（`device.sound.speaker`）、偽の再生器でのテスト。音声ファイルはまだ無いので、遊び方は変わらない。
3. （聞き比べ: 候補 6 人の試聴をユーザーが選ぶ。コミットしない）
4. **PR3 1 人目の声**: 書き出しスクリプト（`scripts/voice/build.js`）、読みの直し表、1 人目の音声、保護者画面の「こえ」（端末の声 / 1 人目）、クレジット（このアプリについて・README・`voice/README.md`）、CI の公開対象。**マージ前に承認**。iPad・iPhone の実機確認。

## 9. ユーザーに確かめる点（推奨つき）

1. **使う声**: 推奨 = 四国めたん（既定）＋ずんだもん。聞き比べ（8 章の 3）のあとで決めてもよい。予備は冥鳴ひまり・雨晴はう・九州そら・玄野武宏。
2. **既定の声**: 推奨 = VOICEVOX の 1 人目（読めないときは自動で端末の声）。代わりの案: 既定は端末の声のままにして、保護者が選んだときだけ切り替える。
3. **子どもの名前を呼ぶ文**: 推奨 = その文だけ端末の声で読む。代わりの案: VOICEVOX の声を選んでいるときは名前を呼ばない（声がそろう）。
4. **`file://` で開いたときは端末の声のまま**でよいか: 推奨 = よい（手元の確認は簡易サーバーで）。
5. **iPhone の消音スイッチ**: Web Audio の音は消音スイッチで消える（効果音は今もそう）。端末の声は消えない場合がある。実機で確かめ、VOICEVOX の声も消えるなら、消音スイッチでも鳴らす設定（`navigator.audioSession.type = 'playback'`。効果音も鳴るようになる）にするか決めたい。推奨 = 実機確認のあとで決める。
6. **公開の承認**: PR3 のマージ（音声を含むテスト版の公開）の前に承認をもらう。
7. **事業として公開する予定**があるか（法人・個人事業として出すと、外した青山龍星などの条件にかかる。推奨の 2 人はどちらでも条件が同じ）。
8. **春日部つむぎ**を使いたい場合は、規約のページ（https://tsumugi-official.studio.site/rule）を開いて本文を確かめてほしい（こちらでは取れなかった）。
